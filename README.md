# Ghost In Shell (記憶系統協議) 🐚 🧠

> **賦予 AI 靈魂的構造圖 (The Blueprint of Soul)**

`Ghost_In_Shell` 是一套專為 AI Agent 設計的記憶與身份管理協議。透過索引式記憶入口與模組化的身份定義，本系統旨在解決 AI 在長期協作中面臨的 Token 高昂、一致性缺失以及維護困難等痛點。

---

## 🚀 核心優勢

- **Token 燃燒抑制**：採用「索引入口 (Gateway Strategy)」，僅在需要時載入細節，大幅節省運算成本。
- **靈魂一致性 (Soul Consistency)**：透過 `IDENTITY.md` 與 `SOUL.md` 的三位一體定義，確保 Agent 在不同任務展現穩定人格。
- **AI 友好的 PARA 架構**：專為 AI 優化的檔案組織方式，讓 Agent 能精準定位所需資訊。
- **自我進化機制**：內建迭代備份與自我優化規範，讓 Agent 隨著每一次任務成長。

## 🛠️ 快速部署 (Starter Kit)

如果你想立即為你的 AI 夥伴建立這套系統，請查看 [`_starter_kit/`](_starter_kit/) 目錄：

1. **結構初始化**：將 `_starter_kit/structure/` 中的資料夾複製到你的工作區。
2. **設定初始化**：參考 `_starter_kit/config/` 中的模板，填寫你的 Agent 資訊。
3. **自動化指令**：利用 `create_agent.py` 快速生成新 Agent 的初始環境。

👉 **[查看 Starter Kit 詳細指南](_starter_kit/README.md)**
